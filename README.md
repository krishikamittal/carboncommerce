# CarbonCommerce

AI-powered B2B procurement platform that optimizes for Cost, Carbon, and Reliability — not just price.

Built for UniHack (Hack2Skill) 2026.

## Problem Statement

Procurement decisions today are made almost entirely on price and delivery time, while supplier carbon emissions stay invisible. This leads to unnecessary high-emission sourcing even when better options exist.

## Solution

CarbonCommerce helps buyers compare suppliers on cost, carbon footprint, and reliability side by side, using AI to recommend the most balanced option — then generates a verifiable digital carbon passport for every purchase.

## Features

- Supplier discovery and comparison
- AI-powered carbon footprint estimation
- Weighted ranking (Cost / Carbon / Reliability)
- QR-based digital carbon passport
- Procurement emissions dashboard

## Tech Stack

- Frontend: React / Next.js
- Backend: FastAPI
- Database: PostgreSQL
- AI: Gemini API
